Run each section in a separate PowerShell terminal. Start each terminal in the project root.

TERMINAL 1 - Java API

$secureDbPassword = Read-Host "Enter MySQL password" -AsSecureString
$dbPasswordPointer = [Runtime.InteropServices.Marshal]::SecureStringToBSTR($secureDbPassword)
try { $env:HIREBASE_DB_PASSWORD = [Runtime.InteropServices.Marshal]::PtrToStringBSTR($dbPasswordPointer) } finally { [Runtime.InteropServices.Marshal]::ZeroFreeBSTR($dbPasswordPointer) }
mvn -q -DskipTests compile dependency:build-classpath "-Dmdep.outputFile=target/dependencies-classpath.txt"
$dependencies = (Get-Content target\dependencies-classpath.txt -Raw).Trim()
java -cp "target\classes;$dependencies" App

TERMINAL 2 - Python analysis service

Set-Location .\python-ml-service
# Run once for a fresh Python environment:
python -m pip install -r requirements.txt
python app.py

TERMINAL 3 - Static frontend

python -m http.server 8000

Open http://localhost:8000/ in your browser.
